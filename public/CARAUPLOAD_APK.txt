PANDUAN UPLOAD BERBAGAI VERSI APK SORASTREAM
============================================

Website otomatis mendeteksi semua file .apk asli yang Anda upload,
termasuk banyak versi sekaligus (misalnya sorastreamv2.apk, sorastreamv3.apk, dll).

CARA 1 — Upload ke GitHub Releases (Direkomendasikan, tanpa batas 25 MB)
1. Buka repository GitHub Anda -> menu "Releases" -> "Draft a new release".
2. Isi Tag versi (misal v2.0, v3.0), lalu unggah file .apk Anda ke bagian "Attach binaries".
3. Klik "Publish release".
4. Setiap versi Release yang punya file .apk akan otomatis muncul saat tombol Unduh diklik.

CARA 2 — Upload ke folder public/ (Jika ukuran APK di bawah 25 MB)
1. Unggah file .apk asli Anda ke folder public/ lewat GitHub ("Add file" -> "Upload files")
   atau git push, misalnya:
   - public/sorastream.apk
   - public/sorastreamv2.apk
   - public/sorastreamv3.apk
   (Jangan membuat file .apk lewat editor teks karena hanya menghasilkan file kosong.)
2. Semua file .apk valid di folder public/ akan otomatis tampil di daftar pilihan versi.
